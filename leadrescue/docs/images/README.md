# Images

| File | What it is |
|---|---|
| `leadrescue-hero.png` | Front-page banner. **Stand-in:** currently a screenshot of the sign-in screen. Replace it with the LeadRescue banner artwork (same file name). |
| `cloudquest-lineup.png` | CloudQuest companion lineup. **Stand-in:** currently the "Planned companions" section of the app. Replace it with the CloudQuest lineup artwork (same file name). |

Keep each image under about 1 MB so the README loads quickly. To regenerate the screenshots, run the app with `npm start` and capture at 1280x800.
